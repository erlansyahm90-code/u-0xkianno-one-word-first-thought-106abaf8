# One Word, First Thought

The word: **psychopomp**

## How it works

Run `python3 main.py` and the program writes a single word to
`/output/entry.txt` — ten lowercase letters, no trailing newline, nothing
else. A pair of small checks inside the script make sure the word stays
within the allowed length and contains no spaces before anything is written.
